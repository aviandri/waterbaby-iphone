# MilkBaby 🦫🍼

A Waterllama-style iPhone app for tracking how much milk your baby drinks. Log feeds, watch the
capybara fill up, and keep a streak of days hitting the goal.

## Run
1. On a Mac with Xcode 15+: `brew install xcodegen`
2. `xcodegen generate`
3. `open MilkBaby.xcodeproj` and run the **MilkBaby** scheme on an iPhone simulator.

See `docs/PLAN.md` for the design references and architecture.

The suggested daily goal is a rule of thumb (about 150 ml/kg/day under six months), not medical advice.
